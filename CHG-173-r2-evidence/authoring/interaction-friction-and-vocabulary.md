# Authoring friction and vocabulary observations

- **Governed blueprint edits.** The first four completed reports required 62–66 recorded semantic action events, 15–16 context switches, and 7–8 modal openings. Each began from a governed report blueprint, required no component insertion, and required zero or one manually counted layout/style action. Authors still move between editor, inspector, table editor, Report Hub details and Preview to reconcile report title, metrics, narrative, table and data.
- **Data work remains expert-shaped.** `Data First`, category/value versus x/y roles, analysis recipes, mapping, and transform semantics are visible in the interaction log. Users must understand which field is categorical/numeric and how a role is shared between visuals. The ambiguous scene is safe because the user explicitly selects a field.
- **Reuse discovery.** The guided reuse command is reached from the Personal Preset Library. This works in the tested flow, but “preset” does not strongly signal that a full source report can be remapped. The remap itself required 13 mapping actions across shared chart roles. The compatibility dialog groups per-visual roles and can require explicit field selection.
- **Blank build burden.** The manually rebuilt holdout used 109 semantic action events, 28 context switches, 10 library insertions and 8 repeated/manual layout setup actions. It then used Review Smart composition. Reuse avoided 25 action events, 10 context switches, 10 insertions and 8 layout/setup actions in the equivalent service report.
- **Save and recover.** Save/reload points, undo/redo and history are explicit in the remap log. A competing edit is recovered as a new revision. CHG-178’s first wrapper preserved four successful conflict receipts then failed at a final UI-selection wait; a separate supported UI history-select/restore receipt succeeded. Both are preserved.
- **No universal SLA.** Wall-clock times were not used as a product threshold. Counts describe this deterministic run and should not be generalized to user populations.
