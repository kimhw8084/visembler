# Fresh whole-report benchmark brief

Six complete report compositions use run-owned synthetic evidence. A–D begin from intended reusable blueprints; E and F start from Blank canvas. E is a monthly order/returns holdout. F is a bridge reopening decision with a sparse evidence shape. Each has a new report ID; F content is not reused from CHG-209.

A covers executive KPI/business decision; B semiconductor RCA; C experiment/analytical decision; D dense technical shift/status review; E dense mixed evidence; F sparse decision led. Reports include realistic labels, identifiers, values, tables, comparisons, uncertainty and actions.

Full reading scenes: 1440 desktop and 390 narrow for all six; 320 narrow for dense B and D; those two 320 captures are separate fresh sessions with matching stories/values and distinct report IDs. Per-scene review names task, person, decision, truth, character/negative identity, density, salience, type roles, spacing, surfaces, feature/support, color, data density, tone, responsive behavior, and possible misunderstanding.

The information architecture differs across tasks within shared Visembler styling. The audit did not fail the set only for shared product identity. Actual task success and populated pixels were assessed separately. No aesthetic scores or human preference claims are made.
