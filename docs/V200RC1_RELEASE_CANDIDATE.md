# Company UI 2.0.0rc1 — Release Candidate Report

## Purpose

This release candidate is the first v2 implementation wave built directly on the authoritative v1.7.3 contract/evidence-hardened baseline. It does not authorize a visual redesign or weaken any established runtime/design law.

## Implemented v2 transformations

| Area | v2.0.0rc1 implementation | Contract effect |
|---|---|---|
| Release identity | `release_authority.json` + governance verification | duplicated version authorities cannot silently diverge |
| Geometry | named micro/inner/control/surface/overlay/pill/circle radius tokens | primary 10/14/18 constitution remains enforced |
| Layering | canonical sticky/sidebar/header/popup/overlay/modal/tooltip/toast/skip-link layers | large literal z-index escalation is rejected |
| Public API | deterministic signature-aware API contract | root public compatibility surface is frozen for 2.0 |
| Commands | fuzzy ranking, context, disabled state, recent ordering, async-safe execution | palette cannot bypass command-state policy |
| Responsive | six canonical viewport profiles | browser/live certification consumes one viewport authority |
| Accessibility | programmatic dialog/drawer naming, keyboard palette behavior, focus rules | accessibility becomes a machine-governed contract |
| Controls | slider callbacks/validation, zero-width ranges, checkbox group disabled/callback, Space activation | real runtime behavior is more complete |
| Browser routes | phantom `/feedback` target removed; checks moved to `/forms` | certification targets rendered product routes only |
| Content resilience | Korean/English + unbroken-ID torture fixture | mixed-language overflow becomes a browser gate |
