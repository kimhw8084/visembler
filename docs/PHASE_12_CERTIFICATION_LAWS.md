# Phase 12 Certification Laws

1. A release candidate must pass the complete inherited regression suite.
2. Every canonical example must pass strict Company UI static validation.
3. The application shell must install every framework visual layer automatically.
4. Standard UI icons must resolve to packaged semantic SVG assets.
5. No required CDN, remote font, remote icon, or remote runtime visual resource is permitted.
6. The comprehensive review HTML is the integrated visual target, not proof of live NiceGUI pixel equivalence.
7. Live NiceGUI 3.15.0 browser certification is mandatory before production certification.
8. Company proxy/WebSocket and authentication adapters must be verified in the actual company environment.
9. Failed or unavailable certification gates must remain visible; they must never be silently converted to pass.
10. Phase 13 performance/convenience hardening begins only after Phase 12 RC approval.
