Phase 4 UX laws

The framework chooses interaction surfaces by purpose rather than appearance.

Drawer = contextual work

Inspect or edit while preserving the underlying analytical context.

Dialog = focused decision

Use for confirmations and short, blocking tasks—not entire applications.

Popover/menu = lightweight action

Small contextual choices; always dismissible and keyboard reachable.

Feedback stays contextual

Skeleton for content loading, spinner for short action, progress when measurable, state view for durable conditions.
